Model Shelf

One local library for every AI model on your Mac. No duplicate gigabytes, no lost models.

# Ollama, LM Studio and Hugging Face each keep their own copy
~/.ollama/models          same weights
~/.lmstudio/models        same weights
~/.cache/huggingface      same weights

# msh finds the duplicates by SHA-256 and keeps one shelf
✓ one copy on the shelf, the others become links
✓ every app still finds its model
✓ every change can be undone

The problem

Copies everywhere

Every local AI app downloads and stores its own copy of the same model, so one model can quietly take up its size two or three times over.

No single list

Models live in different folders with different names, so it's hard to see what you have, how big it is, and what is safe to remove.

Risky clean-ups

Deleting by hand can break an app that still points at the file. msh links instead of deleting, and keeps a way back.

How it works

  1. Scan the model folders of Ollama, LM Studio and Hugging Face.
  2. Fingerprint each model file with SHA-256, so identical weights match even when their names differ.
  3. Shelve one copy and replace the others with links, so each app keeps working and the disk space comes back.
  4. Undo any change if you need to.
